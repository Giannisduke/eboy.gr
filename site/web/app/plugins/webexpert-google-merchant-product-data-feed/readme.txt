== Description ==

Το πρόσθετο Web Expert WooCommerce Google Merchant Product Data Feed XML Feed δημιουργεί αυτόματα ένα αρχείο XML με τα προϊόντα σας, και ενημερώνεται συνεχόμενα μέσω WP ή real cron.

Με την αγορά του πρόσθετου θα λάβετε ένα συμπιεσμένο αρχείο το οποίο θα εγκαταστήσετε στην ιστοσελίδα σας. Η εγκατάσταση μπορεί να γίνει είτε από εσάς είτε από εμάς, η επιλογή είναι δική σας. Όταν εγκατασταθεί και ενεργοποιηθεί με επιτυχία το πρόσθετο, θα δημιουργηθεί μία νέα σελίδα με όνομα Web Expert. Σε αυτή έχει προστεθεί η σελίδα με τις ρυθμίσεις του Πρόσθετου. Στη σελίδα Wellcomm XML Feed, θα ορίσετε κάποιες παραμέτρους για τη σωστή παραγωγή του αρχείου.

Συγκεκριμένα θα δηλώσετε την Μάρκα, το Χρώμα και το Μέγεθος σε ποιες μεταβλητές του Woocommerce ανήκουν.

Έπειτα, θα θέσετε ποιο κείμενο επιθυμείτε να εμφανίζεται σε περίπτωση διαθεσιμότητας αλλά και μη, των προϊόντων σας.

Τέλος, σας δίνεται η δυνατότητα προσθήκης φίλτρων και αποκλεισμού προϊόντων βάσει κατηγοριών, ετικετών, ιδιοτήτων, καθώς και ορισμένων overrides.

== Installation ==

Με την επιτυχή αγορά του πρόσθετου Web Expert WooCommerce Google Merchant Product Data Feed XML Feed θα δημιουργηθεί ένας λογαριασμός χρήστη, απο όπου μπορείτε να κατεβάσετε το συμπιεσμένο αρχείο σε μορφή zip. Αποθηκεύστε το στον υπολογιστή σας για να ξεκινήσετε στη διαδικασία εγκατάστασης του. Εάν θέλετε μπορούμε να σας το εγκαταστήσουμε και εμείς, για δική σας ευκολία. Τα βήματα εγκατάστασης είναι τα εξής:

1. Από το μενού διαχείρισης επιλέγετε Πρόσθετα, και συγκεκριμένα Νέο Πρόσθετο.
2. Εκεί θα εντοπίσετε πάνω αριστερά το κουμπί Μεταφόρτωση αρχείου. Μόλις το πατήσετε θα εμφανιστεί η φόρμα προσθήκης αρχείου.
3. Επιλέγοντας το κουμπί Επιλογή αρχείου, θα σας εμφανιστεί ένα παράθυρο. Σε αυτό εντοπίστε το zip αρχείο, που αποθηκεύσατε προηγουμένως, και πατήστε το κουμπί Εγκατάσταση τώρα.
4. Μόλις το πρόσθετο ανέβει με επιτυχία στην ιστοσελίδα σας θα σας ζητηθεί να το ενεργοποιήσετε. Σε αυτό το σημείο θα επιλέξετε το κουμπί ενεργοποίησης και το προσθετό σας έχει εγκατασταθεί και ενεργοποιηθεί με επιτυχία.
5. Τέλος, μεταβείτε στις ρυθμίσεις και ορίζετε τις παραμέτρους που λείπουν.
6. Κοινοποιείτε τη διεύθυνση του XML στο Google Merchant.

= Επεξήγηση επιλογών =

Μάρκα
Ορίζετε τις ιδιότητες ή τις ταξινομίες της Μάρκας

Χρώμα
Ορίζετε τις ιδιότητες ή τις ταξινομίες του χρώματος

Μέγεθος
Ορίζετε τις ιδιότητες ή τις ταξινομίες του μεγέθους

Περιγραφή
Ορίζετε απο ποιο πεδίο θέλετε να εκτυπώσετε την περιγραφή

Χρόνος ανανέωσης XML
Ορίζετε τον χρόνο κατά τον οποίο το αρχείο XML θα αναδημιουργείται, χρησιμοποιώντας τον WP Cron.

Φίλτρα προϊόντων
Μπορείτε να φιλτράρετε ποια προϊόντα θα εμφανίζονται στο XML και ποια όχι. Μπορείτε να εμφανίσετε/αποκρύψετε προϊόντα βάσει κατηγορίας, ετικέτας ή ιδιότητας.

Παρακάμψεις
Εξατομικευμένο πεδίο ID
Μπορείτε να ορίσετε το πεδίο που θα αντλείται το ID του είδους. Αφήστε το κενό για να αντληθεί από το προκαθορισμένο πεδίο του WooCommerce

Εξατομικευμένο πεδίο MPN
Μπορείτε να ορίσετε το πεδίο που θα αντλείται ο MPN. Αφήστε το κενό για να αντληθεί από το προκαθορισμένο πεδίο του πρόσθετου Web Expert WooCommerce Google Merchant Product Data Feed XML Feed

Εξατομικευμένο πεδίο GTIN
Μπορείτε να ορίσετε το πεδίο που θα αντλείται ο GTIN. Αφήστε το κενό για να αντληθεί από το προκαθορισμένο πεδίο του πρόσθετου Web Expert WooCommerce Google Merchant Product Data Feed XML Feed

Εξατομικευμένο πεδίο Βάρος
Μπορείτε να ορίσετε το πεδίο που θα αντλείται ο GTIN. Αφήστε το κενό για να αντληθεί από το προκαθορισμένο πεδίο του πρόσθετου Web Expert WooCommerce Google Merchant Product Data Feed XML Feed

Μέγιστο Page Size
Εάν παρατηρείτε timeouts ή εμφανίζεται μια λευκή οθόνη κατά την εκτέλεση εξαγωγής του αρχείου XML, δοκιμάστε να μειώσετε αυτήν την τιμή.

Σε περίπτωση που επιθυμείτε το XML να βγαίνει μέσω cron job ή WP CLI και όχι WP Cron, πρέπει να καλέσετε το αρχείο cron.php
/usr/local/bin/php wp-content/plugins/webexpert-google-merchant-product-data-feed/cron.php
wp-cli webexpert-google-xml generate
