Το πρόσθετο Web Expert Piraeus Bank WooCommerce Payment Gateway προσθέτει στην ιστοσελίδα σας την πύλη πληρωμών της Τράπεζας Πειραιώς για το WooCommerce.

== Description ==

Το πρόσθετο Web Expert Piraeus Bank WooCommerce Payment Gateway προσθέτει στην ιστοσελίδα σας την πύλη πληρωμών της Τράπεζας Πειραιώς για το WooCommerce.

Με την αγορά του πρόσθετου θα λάβετε ένα συμπιεσμένο αρχείο το οποίο θα εγκαταστήσετε στην ιστοσελίδα σας. Η εγκατάσταση μπορεί να γίνει είτε από εσάς είτε από εμάς, η επιλογή είναι δική σας. Όταν εγκατασταθεί και ενεργοποιηθεί με επιτυχία το πρόσθετο, θα δημιουργηθεί μία νέα σελίδα στις ρυθμίσεις του WooCommerce. Η σελίδα ονομάζεται Piraeus bank Gateway και θα τη βρείτε μέσα στην καρτέλα Ταμείο.

Αρχικά, πρέπει να ενεργοποιήσετε την πύλη των πληρωμών, επιλέγοντας Ενεργοποίση πύλης πληρωμών. Σε περίπτωση που επιθυμείτε να κάνετε κάποιες δοκιμαστικές αγορές για να ελέγξετε την ορθή λειτουργία του συστήματος σας, μπορείτε να ενεργοποιήσετε το Test Environment.

Έπειτα, θα προσθέσετε τα στοιχεία που θα παρουσιάζονται στον πελάτη σας κατά την ολοκλήρωση της παραγγελίας του, όπως ο τίτλος και η περιγραφή της συγκεκριμένης υπηρεσίας πληρωμής.

Επιπλέον, θα προσθέσετε τα προσωπικά σας στοιχεία, τα οποία θα λάβετε από την τράπεζά σας. Ακόμη υπάρχει και η λειτουργία Προ – Έγκριση. Ο προ επιλεγμένος τρόπος πληρωμής είναι Αγορά, ενεργοποιήστε για Προ-Έγκριση πληρωμών. Στη συνέχεια θα πρέπει να αποδέχεστε τις πληρωμές μέσα από το Admin Tool της Τράπεζας Πειραιώς.

Τέλος, θα πρέπει να ορίσετε το μέγιστο αριθμό από τις άτοκες δώσεις που προσφέρει το κατάστημά σας, καθώς και τη σελίδα επιστροφής του πελάτη μετά την ολοκλήρωση της πληρωμής.

== Installation ==

Με την επιτυχή αγορά του πρόσθετου Web Expert Piraeus Bank WooCommerce Payment Gateway θα δημιουργηθεί ένας λογαριασμός χρήστη, απο όπου μπορείτε να κατεβάσετε το συμπιεσμένο αρχείο σε μορφή zip. Αποθηκεύστε το στον υπολογιστή σας για να ξεκινήσετε στη διαδικασία εγκατάστασης του. Εάν θέλετε μπορούμε να σας το εγκαταστήσουμε και εμείς, για δική σας ευκολία. Τα βήματα εγκατάστασης είναι τα εξής:

1. Από το μενού διαχείρισης επιλέγετε Πρόσθετα, και συγκεκριμένα Νέο Πρόσθετο.
2. Εκεί θα εντοπίσετε πάνω αριστερά το κουμπί Μεταφόρτωση αρχείου. Μόλις το πατήσετε θα εμφανιστεί η φόρμα προσθήκης αρχείου.
3. Επιλέγοντας το κουμπί Επιλογή αρχείου, θα σας εμφανιστεί ένα παράθυρο. Σε αυτό εντοπίστε το zip αρχείο, που αποθηκεύσατε προηγουμένως, και πατήστε το κουμπί Εγκατάσταση τώρα.
4. Μόλις το πρόσθετο ανέβει με επιτυχία στην ιστοσελίδα σας θα σας ζητηθεί να το ενεργοποιήσετε. Σε αυτό το σημείο θα επιλέξετε το κουμπί ενεργοποίησης και το προσθετό σας έχει εγκατασταθεί και ενεργοποιηθεί με επιτυχία.
5. Θα πρέπει να κοινοποιήσετε τα εξής στοιχεία στην τράπεζα
 - Website url	    http(s)://www.domain.gr/
 - Referrer page	http(s)://www.domain.gr/checkout/
 - Success page	    http(s)://www.domain.gr/wc-api/WC_Piraeusbank_Gateway?peiraeus=success
 - Failure page	    http(s)://www.domain.gr/wc-api/WC_Piraeusbank_Gateway?peiraeus=fail
 - Cancel page	    http(s)://www.domain.gr/wc-api/WC_Piraeusbank_Gateway?peiraeus=cancel
 - Response method	GET ή POST
 - IP	            (η διεύθυνση IP)
 - Δόσεις	        0 (Αριθμό δόσεων που επιθυμείτε)
