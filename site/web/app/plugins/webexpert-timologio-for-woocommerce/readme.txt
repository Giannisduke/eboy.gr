Το πρόσθετο Web Expert Timologio for WooCommerce προσθέτει δυνατότητα επιλογής απόδειξης/τιμολογίου/δελτίου παραγγελίας κατά την ολοκλήρωση παραγγελίας. Προαιρετικά ενσωματώνει δυνατότητα απαλλαγής λόγω VIES ή ΠΟΛ.1150/2017, ακόμα και μείωση φόρου για νησιωτικούς ΤΚ.

== Description ==

Το πρόσθετο Web Expert Timologio for WooCommerce δίνει τη δυνατότητα στο χρήστη να επιλέξει αν επιθυμεί έκδοση απόδειξης ή τιμολογίου κατά την ολοκλήρωση παραγγελίας. Σε περίπτωση επιλογής τιμολογίου, εμφανίζονται υποχρεωτικά τα πεδία Όνομα Εταιρίας, ΑΦΜ, ΔΟΥ και δραστηριότητα, χωρίς προβλήματα εμφάνισης ή λανθασμένων μηνυμάτων.
Τα στοιχεία που εισάγει ο χρήστης βρίσκονται στις κατάλληλες θέσεις στην περιοχή διαχείρισης, ενώ εμφανίζονται κανονικά στα email παραγγελίας, καθώς και στον λογαριασμό χρήστη.

Προαιρετικά, μπορείτε να ορίσετε την αυτόματη μετατροπή των χαρακτήρων που πληκτρολογεί ο αγοραστής, σε κεφαλαίους, για τη συμπλήρωση των πληροφοριών τιμολογίου.

Προαιρετικά, μπορείτε να ορίσετε να γίνεται έλεγχος του ΑΦΜ μέσω ΑΑΔΕ και να συμπληρώνονται αυτόματα οι πληροφορίες επωνυμίας του αγοραστή.

Προαιρετικά, μπορείτε να ορίσετε αν επιθυμείτε να γίνεται απαλλαγή του ΦΠΑ, εφόσον δόθηκε οποιοδήποτε ΑΦΜ ή κάνοντας χρήση του VIES και δίνοντας απαλλαγή ΦΠΑ όταν το ΑΦΜ που δόθηκε είναι έγκυρο και χώρας διαφορετικής της επιχείρησης.

Προαιρετικά, μπορείτε να ορίσετε αν επιθυμείτε να γίνεται απαλλαγή του ΦΠΑ, σε συγκεκριμένες κατηγορίες προϊόντων, για την εφαρμογή του ΠΟΛ.1150/2017.

Προαιρετικά, μπορείτε να ορίσετε αν επιθυμείτε να γίνεται μείωση του ΦΠΑ σε πελάτες από νησιά, βάσει ΤΚ και για έγκυρα ΑΦΜ.

Προαιρετικά, μπορείτε να συμπληρώσετε τα πλήρη στοιχεία επιχείρησης που θα αναγράφονται πάνω στα παραστατικά.

Προαιρετικά, μπορείτε να εκδώσετε παραστατικό σε αρχείο PDF ή να ανεβάσετε δικό σας αρχείο παραστατικού, προκειμένου να υπάρχει η δυνατότητα να αποσταλεί ηλεκτρονικά στον χρήστη.

** Για την ΑΑΔΕ **
Για την ενεργοποίηση ελέγχου μέσω της ΑΑΔΕ, θα πρέπει να επισκεφτείτε την ιστοσελίδα https://www.aade.gr/epiheiriseis/forologikes-ypiresies/mitroo/anazitisi-basikon-stoiheion-mitrooy-epiheiriseon και να ακολουθήσετε τα 3 βήματα
1) Εγγραφή στην υπηρεσία κάνοντας χρήση των TAXISnet κωδικών.
2) Απόκτηση ειδικών κωδικών πρόσβασης μέσω της εφαρμογής Διαχείριση Ειδικών Κωδικών.
3) Εισαγωγή των κωδικών πρόσβασης στις ρυθμίσεις του πρόσθετου.

== Installation ==

Με την επιτυχή αγορά του πρόσθετου Web Expert Timologio for WooCommerce θα δημιουργηθεί ένας λογαριασμός χρήστη, απο όπου μπορείτε να κατεβάσετε το συμπιεσμένο αρχείο σε μορφή zip. Αποθηκεύστε το στον υπολογιστή σας για να ξεκινήσετε στη διαδικασία εγκατάστασης του. Εάν θέλετε μπορούμε να σας το εγκαταστήσουμε και εμείς, για δική σας ευκολία. Τα βήματα εγκατάστασης είναι τα εξής:

1. Από το μενού διαχείρισης επιλέγετε Πρόσθετα, και συγκεκριμένα Νέο Πρόσθετο.
2. Εκεί θα εντοπίσετε πάνω αριστερά το κουμπί Μεταφόρτωση αρχείου. Μόλις το πατήσετε θα εμφανιστεί η φόρμα προσθήκης αρχείου.
3. Επιλέγοντας το κουμπί Επιλογή αρχείου, θα σας εμφανιστεί ένα παράθυρο. Σε αυτό εντοπίστε το zip αρχείο, που αποθηκεύσατε προηγουμένως, και πατήστε το κουμπί Εγκατάσταση τώρα.
4. Μόλις το πρόσθετο ανέβει με επιτυχία στην ιστοσελίδα σας θα σας ζητηθεί να το ενεργοποιήσετε. Σε αυτό το σημείο θα επιλέξετε το κουμπί ενεργοποίησης και το προσθετό σας έχει εγκατασταθεί και ενεργοποιηθεί με επιτυχία.
5. Οι ρυθμίσεις του πρόσθετου βρίσκονται στην επιλογή WooCommerce > Φόρος
